# External reference sources

Checked 2026-10-04.

- Cursor Rules: https://cursor.com/docs/rules
- Cursor MCP: https://cursor.com/docs/mcp
- Cursor customization: https://cursor.com/docs/customize-cursor

Current product facts reflected in this kit:
- project rules use `.cursor/rules/*.mdc`;
- project MCP configuration uses `.cursor/mcp.json`;
- global MCP configuration can use `~/.cursor/mcp.json`;
- `AGENTS.md` is supported;
- rules should remain focused and repository-scoped where possible.

These external mechanics do not override INOS authority or mission contracts.
