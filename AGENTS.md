# INOS Repository Agent Instructions

This repository uses the Infinite Network execution-surface boundary.

## Core rule

Agent/runtime capability is not authority.

Read `.cursor/rules/` and the assigned mission/task packet before consequential implementation.

## Planning

For changes spanning multiple subsystems, create a short plan that names:
- objective;
- governing sources;
- files expected to change;
- test plan;
- rollback/recovery concern;
- unresolved gates.

## Verification

Do not claim checks you did not run. Return exact evidence.

## Git

Preserve unrelated work. Do not force-push, merge protected branches, publish releases, or deploy without explicit authority.
